# Report design notes

I use orange as the main accent and blue for the evening trend. I took ideas from my BASF and Rhein-Neckar reports: clear cards, large values and quiet chart areas.

The page is 1,600 by 1,000 pixels. Filter labels sit above the menus. The four main values use 48-point text. Smaller quality cards use 32-point text.

The background has simple shapes, dots and lines near the page edges. The tram is a generated illustration, not an official rnv photograph. The perspective suggests movement; it is a static image. The image is placed at the lower-right edge and does not cover a chart.

The report uses native Power BI cards, filters and charts. Values stay separate from the background. The data model has not changed.
