# Data

Timetables come from the [official rnv archive](https://gtfs-sandbox-dds.rnv-online.de/).

- `reference/`: the reviewed 2025 holiday and school-break calendar.
- `raw/`: downloaded timetable ZIPs, kept locally.
- `processed/`: results generated by the Python scripts, kept locally.

Run `python scripts/check_2025.py` to download the historical archives. The full execution order is in the main README. Raw and processed files are excluded from Git.
