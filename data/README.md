# Data handling

No transport data are included in this first release.

Future layout:

- raw/: immutable acquired snapshots, subject to source redistribution terms.
- processed/: generated analytical tables.
- manifests/: versioned provenance, licence, timestamps and checksums.

Raw and processed directories are ignored by Git. If redistribution is restricted, provide retrieval instructions rather than uploading the data. Commit source manifests and small reviewed reference tables only after checking their terms.

Never commit credentials, personal travel traces, local Power BI caches or machine-specific paths.
